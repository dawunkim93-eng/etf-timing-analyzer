# ETF 타이밍 분석

**https://dawunkim93-eng.github.io/etf-timing-analyzer/**

"사람들한테 인기가 식은 섹터·지수를 사는 타이밍"을 찾는 도구.
미국 40종목 · 한국 30종목의 주요 ETF를 52주 최저가 대비 위치와 RSI로 필터링하고,
익절·손절 타이밍까지 보여준다.

---

## 매수 조건 (2개 다 만족)

| 조건 | 의미 |
|---|---|
| **52주 최저가 대비 +10% 이내** | 현재가가 최근 252거래일 최저가에서 10% 넘게 올랐지 않음 = 인기가 식은 지점 |
| **RSI(14) ≤ 50** | 과열되지 않음 |

저점 근접만 보면 계속 떨어지는 중인 종목도 잡히고, RSI 조건이 그걸 걸러낸다.
둘을 같이 쓰면 **바닥을 확인한 반등 후보**만 남는다.

## 매도 조건

| 조건 | 기본값 |
|---|---|
| 익절 | RSI > 60 (엄격 모드 RSI > 70) |
| 손절 | 진입가 대비 -15% |
| 보유 상한 | 63거래일 (1분기) |

## 시장 국면 필터

벤치마크(미국 SPY / 한국 KODEX 200)의 **최근 252거래일 수익률 < 0** 이면 약세 국면.

화면은 두 가지를 **둘 다** 보여준다:
- **1순위** — 원조건 + 약세 국면
- **2순위** — 원조건만 (국면 무관)

이유는 아래 "검증" 절에 있습니다.

## 검증 결과 (10년 백테스트)

`scripts/backtest.py` 가 계산하고, 사이트의 "검증" 탭이 `data/backtest.json` 을 읽어 보여준다.
설명에 적은 숫자를 손으로 적지 않는다.

**미국 ETF 40종목, 2016-10 ~ 2026-10 (일봉)**

| 구성 | 거래 | 평균 | 승률 | 알파 | 포트폴리오 | 연평균 | MDD | 투자비중 |
|---|---|---|---|---|---|---|---|---|
| 원조건만 · RSI>60 익절 | 709 | +0.16% | 63.5% | -0.61% | 1.25배 | +2.56% | -37.5% | 95.4% |
| 원조건만 · RSI>70 익절 | 574 | +1.25% | 52.4% | -0.87% | 1.07배 | +0.76% | -36.3% | 97.9% |
| **약세 필터 · RSI>60 익절** | 280 | **+2.70%** | 62.5% | -0.19% | **1.98배** | **+11.00%** | **-22.9%** | 31.2% |
| **약세 필터 · RSI>70 익절** | 261 | **+6.13%** | 62.5% | +0.07% | 1.96배 | +10.78% | -22.9% | 38.6% |
| 무작위 대조군 | 13,216 | -1.60% | 41.1% | — | — | — | — | — |

같은 기간 SPY: 연 +12.95%, MDD -34.1%

### 결론부터 (솔직하게)

**이 규칙은 지수를 이기지 못했습니다.**

- 신호 진입은 무작위 진입보다 확실히 낫다 (평균 +0.16% vs -1.60%, 승률 63.5% vs 41.1%)
- 하지만 **시장조정 알파는 거의 0** 이다. 지수를 못 이겼다.
- **원조건만 쓰면** 연 +2.56% — SPY(+12.95%)의 1/5. 지수에 못 미친다.
- **약세 국면만 쓰면** 연 +11.00%, MDD -22.9% — 지수와 비슷한 수익을 **낙폭 절반**으로 얻는다.
  단, **투자 비중이 31%** 다. 나머지 시간은 현금이다.

**왜 그런가**
52주 저점 근처 + RSI 50 이하라는 조건은 주로 *약세장 끝부분*에 성립한다.
그때 지수가 이미 많이 떨어졌으니 지수보다 많이 오르기는 어렵다.
반대로 지수가 오른 국면에서는 이 조건을 만족하는 종목이 거의 없다 — 그래서
그 구간의 상승을 따라가지를 못한다.

즉 이 규칙은 **상승을 따라가는 규칙이 아니라 낙폭을 줄이는 규칙**이다.
그래서 1순위/2순위를 나눠 전부 보여준다.

### 버린 규칙

| 규칙 | 결과 | 이유 |
|---|---|---|
| MA50 < MA200 데드크로스 | 평균 -0.04%, 승률 48.6% | 거래 8,598회. 규칙이 무의미 |
| 12-1 모멘텀 | — | 동행지수 바이어스. ETF에 부적합 |
| RSI > 50 익절 | 평균 -0.01% | 너무 빨라 잡음 |
| 트레일링 스톱 (10~15%) | 평균 +0.14% | RSI 익절보다 기여도 낮음 |

### 한계

- **생존 편향** — 지금 살아있는 ETF 만으로 과거를 돌린다. 상장폐지된 3X·인버스 ETF 가 빠져 있다.
- **거래비용·세금 미반영** — 실제로는 더 불리하다. 매번 거래하는 만큼 이 비용이 크다.
- **구간 겹침** — 통계적 유의성이 과장된다.
- **레버리지·인버스 ETF 제외** — 52주 저점 규칙이 의미가 없어진다.
- **한국 ETF 는 원화 기준** — 환율이 빠져 있다.

## 지표 계산 방법

| 지표 | 방법 | 근거 |
|---|---|---|
| 52주 저·고점 | 최근 **252거래일의 일봉 저가/고가** | 야후 메타와 정확히 일치 확인 (SPY 629.28). 종가 기반과 다름 |
| RSI(14) | Wilder 평활, 일봉 종가 | 6개월/1년/2년 구간 모두 같은 값 |
| MA50 / MA200 | 종가 단순이동평균 | |
| 수익률 | 1M=21, 3M=63, 6M=126, 12M=252 **거래일** | 달력일이 아님 |

**Yahoo 메타의 `fiftyTwoWeekLow` 는 한국 ETF 에서 `0.0` 을 반환한다.**
그래서 52주 저·고점은 전부 일봉에서 직접 계산한다.

## 데이터 출처

| 출처 | 용도 | 갱신 |
|---|---|---|
| Yahoo Finance `query2` chart API | 일봉 (미국·한국 ETF) | 장중 30분 / 장외 2시간 |
| Yahoo Finance screener | 미국 ETF AUM 참고 | 유니버스 정의 시 |
| 네이버 `etfItemList.nhn` | 한국 ETF 목록 + AUM | 유니버스 정의 시 |

**야후는 일반 HTTP 클라이언트로 429 로 막는다.** `curl_cffi` 의 브라우저 TLS 지문
(`impersonate="chrome"`)을 쓴다. 의존성은 이것 하나뿐.

## 구조

```
index.html            SPA 셸 (5개 탭)
app.js                렌더링 · 필터 · SVG 스파크라인 (프레임워크 없음)
styles.css            CSS 변수 체계
data/etf_us.json      미국 데이터 (생성물)
data/etf_kr.json      한국 데이터 (생성물)
data/history.json     일별 스냅샷 누적 (생성물)
data/backtest.json    백테스트 결과 (생성물)
scripts/universe.py   ETF 유니버스 + 규칙 상수
scripts/fetch_etf.py  수집 + 지표 계산
scripts/validate_data.py  데이터 무결성 검사
scripts/backtest.py   백테스트
```

## 로컬 실행

```bash
pip install -r requirements.txt
python scripts/fetch_etf.py all      # 수집
python scripts/validate_data.py      # 무결성 검사
python scripts/backtest.py --refresh  # 백테스트
python -m http.server 8000           # http://localhost:8000
```

## 자동 갱신

GitHub Actions 가 30분마다(장중) · 2시간마다(장외) 실행해서
`data/*.json` 을 갱신하고 커밋한다. 실질 변화가 없으면 커밋하지 않는다.
변경이 push 되면 Pages 가 자동 재배포한다.
